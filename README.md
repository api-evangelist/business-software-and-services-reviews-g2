**Human URL:** [https://data.g2.com/api/v2/docs/index.html](https://data.g2.com/api/v2/docs/index.html)

**Base URL:** https://data.g2.com/api/v2/

- Competitive Intelligence

#### Features

- OAuth 2.0 Authentication
- Buyer Intent Signals
- Competitive Intelligence Data
- Review Analytics

- Software Product Data

#### Use Cases

- CRM integration for buyer intent signals

- Sales prospecting with intent data
- Marketing campaign targeting
- Software evaluation workflows

### G2 Buyer Intent Data API
G2 Buyer Intent Data provides signals about companies actively researching software categories, products, and competitors on G2. Tracks nine signal types and returns company identification, size, industry, and buying stage data.

**Human URL:** [https://documentation.g2.com/docs/buyer-intent-data-reference](https://documentation.g2.com/docs/buyer-intent-data-reference)

**Base URL:** https://data.g2.com/api/v2/

#### Features

- Nine Signal Types (Profile, Pricing, Alternatives, Category, Compare, Sponsored Content, Licensed Content, Reference Page, Competitive)
- Company Identification (Name, Domain, ID)
- Company Classification (Sector, Industry, Sub-industry)
- Organization Size Data
- Buying Stage Classification (Awareness, Consideration, Decision)
- Activity Level Metrics (Low, Medium, High)
- Page-Level Visit Data

#### Use Cases

- Identify in-market buyers researching your product
- Prioritize sales outreach by buying stage
- Monitor competitive research activity
- Personalize marketing based on buyer intent
- Account-based marketing (ABM) targeting

### G2 MCP Server
The G2 MCP (Model Context Protocol) Server enables AI assistants like Claude to access G2 data. Uses OAuth for authentication. Provides access to buyer intent intelligence, competitive intelligence, and review analytics within AI workflows.

**Human URL:** [https://documentation.g2.com/docs/g2-mcp-server](https://documentation.g2.com/docs/g2-mcp-server)

#### Features

- OAuth Authentication
- Buyer Intent Intelligence
- Competitive Intelligence
- Review Analytics
- AI Integration Support

#### Use Cases

- AI-powered sales intelligence
- Automated competitive research in AI workflows
- LLM-powered buyer intent analysis
